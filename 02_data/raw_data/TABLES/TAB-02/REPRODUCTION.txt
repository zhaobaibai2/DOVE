输入和规模：
Positive-only / ER w/o CPCal / CPCal only / Full DOVE，分别 50 / 50 / 46 / 46 个 checkpoint，共 192。
每个 checkpoint 使用同一批 256 个 intervention pairs；每对采样 64 个无 guidance 的 actor 动作。
VLB 覆盖全部 20 个 VP 扩散时间步，每步 64 个正负动作共享噪声，固定 noise_seed=20260810。
模型、args、输入对均已本地保存；运行不需要旧 Backup 目录。模型不是独立训练种子的重复实验。
本表的 reference 是核对依据，未用来替代新模型的推理输出。

指标：
rho_VLB：对全部 pair-checkpoint 统计 Delta_VLB > 0 的比例。t1 decoder variance=beta1，之后用 posterior variance。严格使用原 VP schedule 和终端项。
HSR：每个 pair 的 64 个采样动作中，(a - (a_h+a_n)/2) dot (a_h-a_n) / ||a_h-a_n||^2 > 0 的比例。
RMR_0.5：采样动作满足 ||a-a_n|| < 0.5*||a_h-a_n|| 的比例。
PairAcc_C_mean：同一 256 对、同一 checkpoint 集合上，target twin critics 均值满足 Qbar_n > Qbar_h 的比例。
逐 pair 整数计数汇总；无缩放、拟合或按论文目标替换。checkpoint SD/SE 另外保留。

全量重算：evaluations/20261110_145128_416502。
192 个 checkpoint、49152 个 pair-checkpoint、3145728 个实际 actor 采样动作。
全部 VLB 指示量与原 64-noise 审计逐样本一致。
四组 HSR/RMR 与已有 64-sample 记录逐 pair 一致；critic 与原 Qbar 在当前 256 对子集上的排序逐 pair 一致。
