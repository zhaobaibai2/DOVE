TAB-04：真实车辆阶段诊断
运行 bash scripts/run_tab04.sh test（或本表 run.sh test），读取本表全部本地原始轨迹后自动计算。
collection_repair.csv 含 30475 行；Data Collection 阶段 7514 行，PVP Learning 阶段 22362 行；其余 599 行是 Offline Pretraining，不混入上述两阶段。
frozen_execution.csv 2629 行；connected_trace.csv 8411 行。
接收率/回退率的分母只计 gate_diagnostics_logged == 1 的真实诊断行；未记录 gate 的占位行不作拒绝。
P95 使用 (n-1)*0.95 的线性插值，时间由秒换为毫秒；时长 max(ts)-min(ts)。
连接轨迹速度 mean 为所有采样均值，max 为真正最大值。旧文稿的 3.11 对应速度 P95，实际最大速度为 3.833，不将两者混用。
本操作重算已有实车记录，不表示重新进行了一次实车驾驶。

输出（均在本表目录内）：
  test_results.csv：终端显示的逐项结果和最终结果，terminal_text 保留原显示文本。
  test_results_时间.csv：本次运行的独立 CSV。
  final_metrics.csv：表中最终指标。
  table_values.csv：精确数值、样本数、SD/SE 和旧表比较（适用时）。
  per_checkpoint.csv / per_phase.csv / per_run.csv / scenario_counts.csv：相应中间聚合。
  calculation_audit.json：输入哈希、计算口径和证据范围。
仿真/诊断全量运行另有 evaluations/时间/，保存真实测量及本次清单；只在全部成功后发布顶层结果。
只重新聚合已有本地记录：bash 本表/run.sh calculate；该操作不执行模型仿真。
TAB-02/03 支持 test --smoke 验证整条链路；该模式在 evaluations 下单独保存，明确标为 smoke，不覆盖正式结果。
每个 calculate.py 独立使用 Python 标准库和本表输入，无需 Backup 或其他表的文件。
